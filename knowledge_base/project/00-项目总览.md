# 灵犀 Code 项目总览

## 一句话定位
灵犀 Code(lingxi-code)是一个基于 **LangChain + PySide6** 的 Windows 原生 AI 编码助手。核心是 Agent 工具调用 · 写盘确认闸门 · 改完自检的验证闭环 · RAG 知识库 · MCP · worktree 隔离的并行子 Agent,任意模型可切。它把一个能读写代码、跑命令、检索资料、自我校验的 AI Agent 装进一个可交互的桌面客户端。

## 技术栈
- 语言/运行时:Python 3.14(注意:旧版 LangChain 的 `ConversationBufferMemory` 等 API 已不可用)。
- Agent 编排:LangChain(手写 agent 主循环,不依赖高层 AgentExecutor)。
- 桌面 UI:PySide6(Qt),主窗口用 mixin 拆分。
- 打包:PyInstaller(产物 exe 名为中文「灵犀Code」)。
- 可选依赖:mcp(MCP 客户端)、jedi/python-lsp-server(代码导航)、tree-sitter(符号提取)。

## 核心能力清单
1. **全流式 Agent 主循环**:stream → 收 tool_calls → 执行工具 → 再 stream,直到没有工具调用。
2. **模型无关**:MiMo / Qwen / Claude / DeepSeek / Ollama / Claude Code CLI + 用户自定义模型,按协议(OpenAI/Anthropic)分发。
3. **内置工具生态**:读写/编辑文件、跑命令(含后台进程)、跨文件搜索、符号跳转、git 只读+写、测试、补丁、计划面板等。
4. **RAG 知识库检索**:对本地 Markdown 资料库做语义检索,两阶段 rerank,带索引一致性校验。
5. **多智能体并行**:spawn_agents 把独立子任务派给子 Agent,各自在 git worktree 隔离区改代码再合并。
6. **MCP 客户端**:连接外部 MCP server,把远程工具动态注入到工具集。
7. **验证闭环**:编码任务声称"完成"前要先验证(跑测试/看 diff),失败自动进入修复循环。
8. **多会话并发**:后台会话边跑、前台切到别的会话,互不串话。
9. **长期记忆**:跨会话记住用户,开口就记得。

## 架构分层(自顶向下)
- **UI 层**(`src/ui/`):ChatUI 主窗口 + 若干 mixin(侧栏、顶栏、确认卡、Markdown 渲染、搜索、RAG 侧栏)。
- **Agent 层**(`src/agent.py` / `src/streaming.py`):主循环 + 流式处理 + 历史管理 + 工具执行。
- **能力层**:工具(`src/tools*.py`)、RAG(`src/rag/`)、子 Agent(`src/subagent.py`)、MCP(`src/mcp_client.py`)、代码智能(`src/codeintel.py` / `src/lsp_client.py`)。
- **状态层**(`src/session.py` / `src/state.py`):会话级状态容器 + 线程路由 + 模块级属性代理。
- **持久化层**(`src/memory.py` / `src/memory_store.py` / `src/projects.py`):会话历史、长期记忆、项目列表,全部并发安全。

## UI ⟷ Agent 解耦
Agent 跑在 worker 线程,通过 `ui.show_message(text, tag)` 之类线程安全的 wrapper 调用 UI;wrapper 内部用 Qt Signal 把渲染任务 queue 到主线程。**跨线程绝不直接碰 Qt 控件**(直接动 QTimer/widget 会让对象失去 thread affinity 永久失活),一律走 Signal。

## 目录速览
- `main.py`:入口(高 DPI + 启动 Qt + 创建 ChatUI + 系统托盘)。
- `src/`:主代码(见各主题文档)。
- `roles/`:角色卡 `.md`(直接作为 system prompt)。
- `knowledge_base/`:本知识库(RAG 语料 + 项目文档)。
- `chat_memory/`:会话 JSON、索引、项目、主题等持久化文件。
