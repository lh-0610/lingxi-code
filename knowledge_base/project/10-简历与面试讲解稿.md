## 高频面试问题预演
**Q:你这个 agent loop 和直接调 API 有什么区别?**
A:它是可中断、可确认(每次改盘弹 diff)、Plan 模式可拦写操作、带完成闸门和自修复的循环。工具调用分片用 AIMessageChunk 累加成完整 JSON,再执行、把 ToolMessage 喂回下一轮。

**Q:RAG 怎么保证检索质量 / 换了配置怎么办?**
A:切块保留标题路径且相邻块重叠避免边界信息丢失;两阶段 rerank 提精度;索引 manifest 记录 kb_dir/模型/端点/切块参数,`anchor_mismatch` 单一判据 fail-closed,配置变了强制重建,绝不拿旧索引答题。

**Q:多个 Agent 并行改代码怎么不冲突?**
A:每个子 Agent 一个 git worktree 隔离副本,文件/命令落点被路由到 worktree,best-effort 沙箱拒绝越界,跑完走 git 合并。

**Q:同步代码怎么用异步的 MCP SDK?**
A:常驻后台线程跑一个 event loop,每个 server 一个保活协程挂在 `async with` 里不返回,调用走 `run_coroutine_threadsafe`;关键是绝不在 loop 线程里同步等 loop 里的任务(会死锁)。

**Q:讲一个你调过的难 bug。**
A:选踩坑记录里的任一条(index.json 竞态 / 坏缓存导致重建报成功却 0 块 / 一维向量崩溃),按"现象→定位→根因→修法→怎么防回归(加了测试)"讲。
