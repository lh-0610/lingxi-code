# 工具系统与安全确认

## 工具的组织
内置工具在 `src/tools.py` 用 `@tool` 装饰器定义,聚合进 `ALL_TOOLS`;`build_all_tools()` / `get_tool_map()` 动态合并内置工具 + MCP 远程工具。工具底座 `src/tools_common.py` 提供路径解析、子 Agent 沙箱、验证状态标记——它**不 import tools**,避免循环依赖。

## 主要内置工具
- **文件**:read_file(分页+行号)、write_file(全量覆盖)、append_file、edit_file(精确字符串替换)、list_directory。
- **命令**:run_command(默认 300s 超时、流式输出、taskkill 杀进程树;`background=True` 转后台跑 dev server);read/list/stop_background_command。
- **搜索/导航**:search_in_file、search_files(ripgrep 风格)、find_definition/find_references(LSP→jedi→search 降级链)、find_tests、related_files、code_map。
- **git**:git_diff/log/status(只读)+ git_stage/unstage/commit(写操作,强制确认,无 push)。
- **测试/检查**:run_tests(pytest)、check_code(ruff/py_compile)、apply_patch(多文件原子补丁)。
- **RAG/记忆/计划/通知**:search_knowledge、remember/forget、update_plan/set_step_status、notify_user。
- **子 Agent**:spawn_agents(并行派生)。

## 路径解析(按项目根)
`_project_cwd()` / `_resolve_path()` 让 `read_file('foo.txt')` 解析到 `state.current_project/foo.txt`;run_command 的 cwd 也是项目根。子 Agent 会话则优先解析到它自己的 worktree。

## 写盘类工具的确认卡
edit/write/append 共用 `_confirm_file_write()`:算出 unified diff → `ui.confirm_edit` 弹蓝色 diff 预览卡 → worker 阻塞等审批。CLI/测试无 UI 时直接放行。这样 AI 的每一次改盘用户都能先看 diff。

## 自我校验闭环(编码核心)
让助手"改完自己发现错、自己修"(对标 Cline/Codex):edit/write/append **成功后**调 `_auto_check_suffix()`,跑静态检查,把问题**追加到工具返回串**里。模型在同一条 ToolMessage 就看到「成功编辑 X」+「⚠️ 自动校验发现问题…」→ 下一轮自然去修。

`_run_code_check()` 的检测顺序:随包 ruff → 开发期 `sys.executable -m ruff` → PATH 上的 ruff → 兜底内置 `compile()` 查语法。Python 只选 `--select F,E9`(pyflakes 正确性 + 语法错),**避开风格噪声**,否则模型会去追无意义的格式问题。

## 打包(frozen)下的解释器选择
打包后 `sys.executable` = `灵犀Code.exe`(不是 python.exe),所以 `sys.executable -m ruff/pytest` 跑不了。因此:
- check_code 的语法检查用**进程内 `compile()`**(不起子进程)。
- run_tests 用 `_resolve_python()` 选解释器:项目 venv(.venv/venv/env)→ 开发期 sys.executable → 系统 PATH 的 python。顺带让它在真实项目里用对环境(项目自己的 venv + 依赖)。

## Plan 模式与遥控白名单
- **Plan 模式**:只读工具(read/search/find_*/code_map/git 只读/remember 等)放行,写工具(edit/write/run_command/apply_patch/spawn_agents)被拦截。
- **MCP 工具**:一律走执行前确认(能干任意事);Plan 模式当写工具拦。
- **网络工具**(fetch_url/web_search):进 Plan 只读,但**不进遥控白名单**(网络外发默认不给远程触发)。
